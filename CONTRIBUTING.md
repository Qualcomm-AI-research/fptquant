# Contributing

Contributions are welcome. For substantial changes, open an issue first so
maintainers and contributors can agree on the approach.

## Before submitting a pull request

- Keep each change focused and include relevant tests or validation.
- Follow the setup and validation commands in [README.md](README.md).
- Run the applicable offline tests, Ruff checks, and formatting checks.
- Describe the change, its motivation, and how it was tested.

## Community standards

All participants must follow the [Code of Conduct](CODE_OF_CONDUCT.md).

By contributing, you agree that your contribution is licensed under the
[project license](LICENSE).
